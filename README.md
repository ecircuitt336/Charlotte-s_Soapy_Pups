# Charlotte's Soapy Pups

This project is a publicly accessible version of the website I created for Charlotte's Soapy Pups, accessible at charlottessoapypups.co.uk, for the benefit of my portfolio. Charlotte's Soapy Pups is a one-to-one dog grooming salon.

The live website is on a private repository, as this was enhanced with the use of AI, and not 100% my own work. Everything you see in this repository was made at my own skill level, with AI only being used to support my learning.

I have received permission from the owner of Charlotte's Soapy Pups to publish this repository.

## Getting started

```bash
npm install
npx vite # Start the local server to try this website out
```
